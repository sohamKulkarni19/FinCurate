How to use this checklist

Complete items in order and retain the named evidence inside the project repository or project notes. A checked box means evidence exists, not merely that someone believes the item is probably true.

Go/no-go ruleDo not begin the full UI build while a blocking data or calculation item remains unresolved. A small proof-of-concept script is permitted and expected during prerequisite validation.

Checkbox state is stored only in this browser's local storage. The export button downloads a small JSON status file that can be committed or shared separately.

Final go/no-go gate

DecisionCondition
GoAll blocking items are complete; every required source has retained evidence; sample ingestion and independent calculations pass; the clean environment works.
Conditional goOnly non-blocking usability or later-milestone items remain, with an owner and target milestone recorded.
No-goAny required data source is inaccessible or not permitted, benchmark TRI identity is uncertain, Direct Growth eligibility is unreliable, or calculation fixtures do not reconcile.
Fallback scope if benchmark data failsDo not silently use price indices or scraped values of uncertain permission. Pause the benchmark milestone, retain independent fund analytics and category-peer comparisons, and revisit the source decision explicitly.

Evidence bundle expected at approval

  • Data-access and terms notes with dates and links.
  • Checksummed sample raw snapshots.
  • Category and eligibility audit report.
  • Benchmark coverage report for all five TRI series.
  • Risk-free methodology note.
  • Independent calculation workbook or script and expected outputs.
  • Clean-machine setup record.
  • Approved milestone plan and named reviewer.
